# SoundStation

A keyboard-only ambient sound player themed on 2000s computer aesthetics with windows for soundtracks, media player and a date-time window. SoundStation lets you play multiple soundtracks simultaneously, giving you the best experience of nature at your desk! The website is designed in a minimal yet spooky theme, containing multiple spooky elements, such as jumpscares, scary icons, horrorful colours and backgrounds. SoundStation can only be used with your keyboard it cannot be used with touch/mouse controls. SoundStation is also interactive and tactile, displaying keypress animations and producing mechanical key-press sound effect while using the website.

## Soundtracks
I've added 9 different ambient environment sounds to SoundStation from the sound of the rain to the waves of the ocean, from the chirping of birds to buzzing cicadas.

## Spooky Elements
I've implemented two different modes in SoundStation, one is `Halo` - a simple dark themed interface, looks clean as if nothing is wrong. On the a other hand, we have the `Spooky` mode which looks completely covered in blood and with all colours looking horrorful..
I've tried my best to make the website look as spooky as possible, I've added elements such as pressing the 0 key will switch the modes between Halo and Spooky. I've also implemented the feature of Dark Hours from JS which checks the the current hours and if it's betwee 12-4AM and if yes it locks the user in Spooky mode!

## How I made it
I used HTML, CSS and JS to develop SoundStation.
HTML and CSS are used for the frontend and the website is heavily dependent on JS for things such as playing soundtracks, volume controls, switching between modes and changing their colours and listening to keypresses.

## Where I struggled & What I enjoyed
The biggest challenge was implementing the songs playback and especially the part of simulatoneous playback of audio. I also stuggled a lot in selected colours for the Halo and Spooky modes! I loved adding spooky features to the website and I've done a lot of brainstroming thinking about spooky ideas to implement and searching for the best relatable icons/images on the internet.
