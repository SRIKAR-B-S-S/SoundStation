# SoundStation

<img width="1920" height="904" alt="image" src="https://github.com/user-attachments/assets/4ee7f4e8-3335-4dbc-86fd-767c784960bf" />


A keyboard-only ambient sound player themed on 2000s computer aesthetics, featuring a Windows XP-like user interface with multiple windows for soundtracks, media player and a date-time window. SoundStation lets you play multiple soundtracks simultaneously, giving you the best experience of nature at your desk! The website is designed in a minimal yet spooky theme, containing multiple spooky elements, such as jumpscares, scary icons, horrorful colours and backgrounds. A date-time window is also added for the users to keep track of time. SoundStation can only be used with your keyboard, making it a keyboard-only website and it cannot be used with touch/mouse controls or even your tab key. SoundStation is also interactive and tactile, displaying keypress animations and producing mechanical key-press sound effect while using the website.
  

## Soundtracks

SoundStation is packed with 9 different ambient environment sounds

1. **Rain**: Rain and distant thunder

2. **Forest**: Chirping birds, flowing water, buzzing insects, rustling leaves

3. **Night**: Buzzing crickets and other insects

4. **Dawn**: Distant and mild bird chirping

5. **Ocean**: Waves of the ocean

6. **Campfire**: Crackling fire

7. **Cicada**: Buzzing of cicadas

8. **Birds**: Chirping of various bird species

9. **Farm** Rustling of tall grass by wind
  
## Spooky Theme
- The website's design is categorised into two mode, `Halo` - a dark-mode with gingham checkers background, muted grey colours and a skull icon at the bottom-left indicating the Halo mode. `Spooky` - is a mode with a red background inspired from blood, horrorful window colours, a vinyl gif with an ASCII Skull in it, slightly red-shaded texts and an eye at the bottom-left indicating the Spooky mode.

### Spooky Elements:
1.  **The `0` Key**: Users can switch between modes using the 0 key.
2. **Dark Hours**: Dark Hours refers to the time between 12AM and 4AM during which ghosts can be seen(or heard), the website is locked in Spooky Mode during the Dark Hours, disabling the user to switch modes using the 0 key.
3. **Eerie Jumpscare**: An eerie jumpscare is triggered when the users try to switch between modes.
4. **Skull & the Observer**: A skull icon is visible at the bottom-left corner of the website during the Halo mode and an Observer Eye can be seen at the bottom-left corner of the website.
5. **Err Icons**: In the Spooky mode, icons indicating errors can be visible on the titlebars of the windows.
6. **"You can't escape the Dark Hours"**: This is a message shown to the user when he tries to switch modes during the Dark Hours.
7. **Vinyl with a Skull**: During the Spooky Mode, the normal vinyl gif transforms into a vinyl with an ascii skull.
